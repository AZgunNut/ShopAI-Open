# ShopAI project discovery

**Suggested repository description:** Offline-first ShopAI engineering drawing recognition: OCR, geometry extraction, feature/dimension association experiments, local AI agents, FreeCAD integration, and a shared AI Zoo.

**Topics:** shopai, engineering-drawings, engineering-ocr, computer-vision, geometry-extraction, dimension-recognition, cad, freecad, local-llm, ai-agents, python, linux, vtracer, opencv, research

**Project purpose:** Make dimensionally correct engineering drawing interpretation a repeatable, locally controlled workflow, then enable editable FreeCAD generation once drawing interpretation is proven.

**Not an installer:** Dependencies, AI model weights and several recent files are not included. This is a historical snapshot with source and compact experimental results and explicit gaps.
