# Licensing status and provenance

This repository is being made public so people can find, inspect, download and fork the ShopAI code and development history. **A code license has not yet been selected or granted.**

The snapshot includes material assembled from multiple development locations and historical experiment records. Some files may have been derived from upstream packages or contain patches; ownership and third-party license requirements are **not completely established**. Do not assume that the repository owner's intent to permit GitHub forking is an open-source license for redistribution outside GitHub, modification, commercial use, or relicensing.

A subsequent provenance audit and an owner-approved `LICENSE` file are needed before making broader open-source licensing claims. Anyone submitting changes should identify any upstream code and its license.
