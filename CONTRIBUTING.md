# Contributing to ShopAI

Please begin with `README.md`, `DOCS/OPERATING_RULES.md`, and `DOCS/COVERAGE_AND_GAPS.md`. The active priority is interpreting engineering drawings, not creating visually plausible CAD solids.

Propose changes on a fork or isolated branch rather than modifying a working ShopAI installation. Explain the exact input, test, expected result, changed files, measured output, and any failure. Preserve baselines and history. Never add arbitrary test timeouts, trial ceilings or token limits. Keep offline-only research data local unless explicitly authorized to publish it.
